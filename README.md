Project Overview

This project focuses on analyzing COVID-19 vaccination data across different states in India. The goal is to understand vaccination trends, compare state-wise performance, and gain meaningful insights through data analysis and visualization.

Objectives
Analyze state-wise vaccination data.
Compare vaccination coverage among states.
Identify trends and patterns in vaccine administration.
Present insights using visualizations and charts.

Tools & Technologies
Python
Pandas
NumPy
Matplotlib
Jupyter Notebook

Key Analysis
State-wise vaccination comparison
Total doses administered
Vaccination trends over time
Data visualization using charts and graphs

Results

The analysis highlights differences in vaccination progress across states and provides a clear picture of vaccine distribution trends during the COVID-19 vaccination drive.
